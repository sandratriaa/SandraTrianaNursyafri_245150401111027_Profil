# Profile Page - Sandra Triana Nursyafri

## Deskripsi

Project ini merupakan tugas membuat satu halaman profil menggunakan Kotlin dan Jetpack Compose pada Android Studio.

## Teknologi

* Kotlin
* Android Studio
* Jetpack Compose

## Komponen yang Digunakan

Project ini menggunakan beberapa komponen utama Jetpack Compose:

* Row
* Column
* Spacer
* Box
* Text
* Modifier
* Icons
